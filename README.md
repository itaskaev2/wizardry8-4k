# Wizardry 8 — 4K без рамок + HD-интерфейс (установщик для Steam-версии)

Ставит на Steam-версию Wizardry 8 всё, что было настроено вручную:

| Что | Как |
|---|---|
| Рендер DirectX7_1 в родном разрешении экрана, 32 бит | `3DVideo.CFG` (разрешение берётся с основного монитора без учёта масштаба Windows, либо `-Width/-Height`) |
| Полноэкранный режим без рамок, 16x анизотропия, 8x MSAA, без водяных знаков | dgVoodoo2 2.87.5 (`DDraw.dll`, `D3DImm.dll`, `dgVoodooCpl.exe`) + `dgVoodoo.conf` (fake fullscreen) |
| HD-шрифты (Jost), интерфейс по краям экрана без растяжения, HD-подсказки | `wiz8hd.asi` + `wiz8hd.ini` + `wiz8hd_fonts\` (мод из репозитория `wizardry8-hdui`) |
| Широкие HD-фоны 16:9: главное меню, экраны загрузки, привал | `wiz8hd_bg\` (42 картинки 3840x2160 + эталоны 640x480 для распознавания) |
| Без логотипа 3dfx | `HKCU\Software\Zeus Software\nGlide2` `Splash=0` |
| Ярлык на рабочем столе | «Wizardry 8 (Fan Patch 4K)» → `Wiz8_v128.exe` |

## Требования

### Система

| Что | Нужно | Зачем и что будет, если нет |
|---|---|---|
| ОС | Windows 10 или 11, 64 бит | dgVoodoo2 и установщик на других ОС не проверялись |
| PowerShell | Windows PowerShell 5.1 (встроен в Windows 10/11) | на нём написаны скрипты; PowerShell 7 тоже должен работать, но не проверялся |
| Видеокарта | с поддержкой Direct3D 11 (любая за последние 10 лет) | dgVoodoo2 переводит старый DirectX 7 игры в Direct3D 11 |
| Монитор | лучше 16:9 (1920x1080, 2560x1440, 3840x2160) | разрешение берётся с основного монитора. HD-фоны нарисованы под 16:9; проверено только на 3840x2160 |
| Место на диске | около 80 МБ в папке игры | 71 МБ — HD-фоны (с `-NoBackgrounds` около 2 МБ: мод, шрифты, dgVoodoo2), плюс резервные копии заменённых файлов |
| Права | обычный пользователь | администратор не нужен, если в папку игры можно писать (для библиотеки Steam обычно можно). Пишется только в папку игры, на рабочий стол (ярлык) и в `HKCU` (настройка nGlide) |
| Интернет | не нужен | только если в `mods\` нет `dgVoodoo2_87_5.zip`: тогда он скачивается с GitHub dgVoodoo2 и проверяется по SHA-256. `-Offline` запрещает скачивание |

### Игра

1. **Wizardry 8 из Steam** (app 245450), установленная полностью. Папка ищется сама: реестр Steam →
   `libraryfolders.vdf` → `appmanifest_245450.acf`. Если игра не из Steam или лежит отдельно — `-GamePath`.
2. **Fan Patch 1.28 — скачать отдельно.** В Steam его нет: Steam ставит оригинальную игру 1.2.4 (`Wiz8.exe`).
   Fan Patch — неофициальный патч русскоязычного сообщества (сборки выкладывает GreatMage, группа Cosmic Forge), добавляет
   `Wiz8_v128.exe`, `Wiz8.dll`, `sr.dll`, `3DSetup1_28c.exe` и папку `Patch128_README`. Нужна сборка **6709**
   (`Wizardry8FanPatchV1.28Build6709`); именно с ней проверен установщик.

   Где взять (на 2026-10-24):

   | Источник | Что там | Состояние |
   |---|---|---|
   | [GamePressure: Fan Patch v.1.2.8 Build 6709](https://www.gamepressure.com/download/wizardry-8-fan-patch-v128-build-6709-mod/z2152ee) | сборка 6709, 12.4 МБ, выложена 2025-07-01 | страница открывается; основной вариант |
   | [ModHQ (RPGHQ)](https://mods.rpghq.org/wizardry-8/350301), [тема на форуме](https://rpghq.org/forums/viewtopic.php?t=5352) | Fan Patch 1.28.6709 | сайт показывает проверку «не бот», откройте в обычном браузере |
   | [Cosmic Forge во ВКонтакте](https://vk.com/club177350708) | новости и сборки от автора | официальная группа автора |
   | ~~PostCount, тема «Wizardry 8 Fan-Patch 1.28»~~ | исходная тема патча | форум закрыт в августе 2026 |
   | ~~Яндекс.Диск из обсуждений Steam~~ | старые сборки 5608–6320 | ссылки удалены |

   Установка патча:
   1. Распаковать архив в папку игры (`...\steamapps\common\Wizardry8`) с заменой файлов: `Wiz8_v128.exe` должен
      оказаться рядом с `Wiz8.exe`.
   2. Один раз запустить `Wiz8_v128.exe`, выбрать язык и выйти. Запускать `3DSetup1_28c.exe` не нужно: разрешение и
      рендер выставит этот установщик.
   3. Кнопку «Check for updates» / «Проверить обновления» в лаунчере патча лучше не нажимать: она ставит более новые
      сборки (6719, 6735), см. п. 4.

   Некоторые антивирусы ругаются на `Wiz8_v128.exe` (патч правит игру в памяти). Авторы сами дают ссылку на проверку
   именно этого файла: [VirusTotal, SHA-256 fdca6d9c…a9fb824](https://www.virustotal.com/gui/file/fdca6d9cd0940034191e82b8e2900de26bb25e381c74128dcb8967360a9fb824/detection)
   (ссылка из `Patch128_README`). Без `Wiz8_v128.exe` установщик остановится с подсказкой.
3. **Именно этот `Wiz8_v128.exe`.** Мод патчит игру в памяти по известным адресам, поэтому exe сверяется по SHA-256
   (`fdca6d9c…a9fb824`, тот же, что на VirusTotal выше). С другим exe установка откажется и ничего не изменит.
   Проверить заранее: `Get-FileHash .\Wiz8_v128.exe` в папке игры или `.\install.ps1 -DetectOnly`.
4. **Сборка Fan Patch (`Wiz8.dll`)**: проверено на 6709 и 6735 (Mini-Update). Обновление до 6735 меняет
   `Wiz8.dll`, а `Wiz8_v128.exe` оставляет прежним (проверено на установке с 6735). С другой сборкой (например, бета 6719) установщик
   только предупредит, мод останется включённым.
5. **Язык Fan Patch** при первом запуске `Wiz8_v128.exe` спрашивает язык (русский / английский / польский). Мод
   работает с любым; на снимках русский.
6. **Игра закрыта.** Если `Wiz8.exe` или `Wiz8_v128.exe` запущены из этой папки, установка и откат откажутся.
7. **nGlide** (необязательно). Steam-версия по умолчанию рисует через Glide (nGlide лежит в папке игры).
   После установки игра рисует через DirectX, а установщик выключает логотип nGlide в реестре (`Splash=0`). Если
   nGlide не установлен, этот шаг ни на что не влияет; пропустить его — `-SkipNGlide`.

Что установщик **не трогает**: сохранения, `wiz8.ini`, `Wiz8.CFG`, оригинальный `Wiz8.exe` и всё в `Data\`.
Проверить всё это без изменений: `.\install.ps1 -DetectOnly` (найти игру, сверить версии, показать разрешение) или
`-WhatIf` (показать список действий).

## Установка

Закрыть игру, затем двойной клик по `install.cmd` или:

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1
```

Папка игры находится сама (реестр Steam → `libraryfolders.vdf` → `appmanifest_245450.acf`). Полезные ключи:

| Ключ | Что делает |
|---|---|
| `-GamePath "D:\...\Wizardry8"` | указать папку вручную |
| `-Width 2560 -Height 1440` | другое разрешение |
| `-WhatIf` | показать, что будет сделано, ничего не меняя |
| `-DetectOnly` | только найти игру, проверить версии и разрешение |
| `-NoHdUi` | только 4K/без рамок, без мода интерфейса |
| `-NoBackgrounds` | мод без пакета HD-фонов (−71 МБ) |
| `-ResetConfig` | перезаписать уже существующие `wiz8hd.ini` / `dgVoodoo.conf` значениями по умолчанию |
| `-NoShortcut`, `-SkipNGlide`, `-Offline` | пропустить ярлык / настройку nGlide / скачивание |

Запускать игру ярлыком «Wizardry 8 (Fan Patch 4K)» (или `Wiz8_v128.exe`). Кнопка «Играть» в Steam запускает
оригинальный `Wiz8.exe` 1.2.4 — там мод сам отключается, а картинка будет растянутой.

Повторный запуск `install.ps1` обновляет установку на месте: оригиналы из первой установки не перезаписываются,
ваши `wiz8hd.ini` и `dgVoodoo.conf` сохраняются.

## Откат

`uninstall.cmd` или `.\uninstall.ps1`. Все заменённые файлы лежат в `<игра>\_wiz8_4k\backup`, список — в
`_wiz8_4k\manifest.json`. Откат удаляет добавленные файлы, возвращает заменённые байт в байт, восстанавливает
значение `Splash` в реестре и прежний ярлык (или удаляет созданный). Сохранения, `wiz8.ini`, `Wiz8.CFG` установщик
не трогает.

## Настройки мода

`wiz8hd.ini` в папке игры: `Aspect`, `Layout` (интерфейс по краям / 4:3 в центре), `Text` (TrueType-шрифты),
`MatchWidth`, `Backgrounds` (HD-фоны), `Log`, секция `[Fonts]` (шрифт и масштаб для каждого игрового шрифта).

## Проверка

`tests\Test-Roundtrip.ps1 -Source "<папка игры>"` собирает маленькие копии папки игры в `tests\_work` (exe, Wiz8.dll,
zip dgVoodoo, исходный `3DVideo.CFG`) и проверяет: `-WhatIf` ничего не меняет; установка кладёт правильные файлы
(хеши); повторная установка не трогает бэкапы и ini игрока; откат возвращает папку к исходному состоянию байт в
байт; ручная установка до нас тоже возвращается; неизвестный exe, отсутствие Fan Patch и zip — отказ. Игру тест не
запускает и пишет только в тестовый ключ реестра и `tests\_work`; в конце проверяет, что настоящий ключ nGlide
и ярлык на рабочем столе не изменились.

`tests\Build-CleanSteamCopy.ps1` собирает чистую копию Steam-версии в отдельную папку по списку файлов с хешами
(источники только читаются) — для проверки в игре без риска для основной установки.

Проверено так 2026-10-24 (копия Steam-версии, Fan Patch 6709, 3840x2160): установка → главное меню с широким
HD-фоном и HD-текстом, мир с интерфейсом по краям и HD-шрифтом → откат вернул копию байт в байт (кроме
`wiz8.ini` и `cfagent.log`, которые пишет сама игра). Привал на 6709 в игре не снимался (окно игры сворачивалось
в фоне); на 6735 он проверен раньше.

## Особенности Fan Patch

- Если Fan Patch нашёл в интернете новую версию, при следующем запуске он показывает свой «Запускатор 1.6»,
  даже с галочкой «Не показывать». Кнопка «Играть» в нём сама скачала и поставила бета-обновление (6719) и
  перезапустила игру. Это поведение Fan Patch, не установщика; после такого обновления `Wiz8.dll` будет
  неизвестной сборкой (мод при этом остаётся включённым — он проверяет только `Wiz8_v128.exe`).
- В полноэкранном режиме без рамок игра сворачивается, когда теряет фокус; это нормально.

## Обновление мода

После пересборки `wizardry8-hdui` (`./build.sh`, `build\wiz8hd.asi` → `dist\`):

```powershell
.\tools\Update-Payload.ps1 -GameConf "<игра>\dgVoodoo.conf"   # -GameConf только если менялся dgVoodoo.conf
```

Скрипт копирует `wiz8hd.asi`, шаблон `wiz8hd.ini` (с `Backgrounds=1`, `Log=0`), шрифты и фоны и пишет
`payload\VERSION.txt` с коммитом исходников. Картинки и шрифты хранятся в Git LFS.

Картинки «до/после» в `docs\` собирает `python tools\make_compare.py <wizardry8-hdui>\shots` из снимков, сделанных
при разработке мода.
